# ClassicLauncher - Android Project

Is project mein tamam naye features aur design fixes shamil hain:
1. Home screen Snake Ring rotating animation.
2. Camera Ring size control (0 tak zero limit).
3. Wheel color update detached from launcher app icon.
4. Side-mounted Fingerprint lock screen animation.
5. Smooth standalone Video Player.
6. Vibrant Theme Presets (Gold, Neon Blue, Purple, Orange, Green, Pink).

## GitHub Par Update & Auto APK Build Kaise Karein:

1. Is ZIP ko extract karein.
2. Apne GitHub account par ek naya Repository banayein (naam rakhein: `ClassicLauncher`).
3. Tamam files ko GitHub repo mein upload ya push karein.
4. `.github/workflows/build.yml` file ki waja se jab bhi aap GitHub par code update karenge, GitHub Actions automatically APK compile karke **Actions** tab mein download ke liye ready kar dega!
